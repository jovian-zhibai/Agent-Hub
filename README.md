## 📖 Overview

Agent Hub is a comprehensive management platform for AI coding assistants and agents. It solves the common pain points of:

- **Multiple API Key Management**: Automatically rotate between keys when one is depleted or rate-limited
- **Cost Monitoring**: Track token usage and costs across all your agents in real-time
- **Permission Control**: Fine-grained control over what tools agents can use and which files they can access
- **Centralized Dashboard**: Monitor all your local agents from a single web interface

Perfect for developers using AI coding assistants like OpenCode, Claude Code, Cursor, or custom AI agents.

## ✨ Features

### 🔑 Smart Key Management
- **Automatic Failover**: Seamlessly switch to backup keys when primary keys fail
- **Health Monitoring**: Real-time key health status and rate limit tracking
- **Multi-Provider Support**: OpenAI, Anthropic, OpenRouter, and custom providers
- **Secure Storage**: AES-256-GCM encryption for all API keys

### 🛡️ Permission System
- **Tool-Level Control**: Allow, deny, or ask for approval per tool type
- **Path-Based Rules**: Restrict file access by path patterns
- **Safety Mode**: One-click lockdown for sensitive operations
- **Audit Logs**: Complete history of all agent actions

### 📊 Cost Analytics
- **Real-Time Tracking**: Monitor token usage and costs as they happen
- **Budget Alerts**: Get notified when agents approach spending limits
- **Detailed Breakdowns**: See costs per agent, model, and time period
- **Export Reports**: CSV/JSON export for accounting

### 🖥️ Modern Dashboard
- **Agent Overview**: See all connected agents at a glance
- **Cost Trends**: Visualize spending patterns over time
- **Quick Actions**: Test keys, update permissions, manage agents
- **Responsive Design**: Works on desktop, tablet, and mobile

## 🚀 Quick Start

### Prerequisites

- **Node.js 18+**
- **PostgreSQL** (or use Docker for automatic setup)
- **npm** or **pnpm**

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/agent-hub.git
cd agent-hub

# Automated setup (installs dependencies, sets up database, generates secrets)
npm run setup

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Connecting Your First Agent

```bash
# Install the CLI globally
npm link

# Connect your local agents
agent-hub connect

# Sync configuration
agent-hub sync
```

The CLI will scan for agents in:
- `.opencode/agents/*.md` (OpenCode)
- `opencode.json` (OpenCode)
- `.claude/opencode.json` (Claude)
- `.agent-hub.yml` (Manual config)

## 📚 Documentation

### Architecture

Agent Hub consists of three main components:

1. **Web Dashboard** (Next.js): Management interface for viewing and controlling agents
2. **CLI Tool**: Command-line interface for connecting agents to the platform
3. **SDK**: TypeScript SDK for integrating Agent Hub into your agents

```
┌─────────────────┐
│  Web Dashboard  │
│   (Next.js)     │
└────────┬────────┘
         │
    ┌────▼─────┐
    │  API     │
    │  Layer   │
    └────┬─────┘
         │
    ┌────▼──────────┐
    │  PostgreSQL   │
    │   Database    │
    └───────────────┘
         ▲
         │
    ┌────┴─────┐
    │   SDK    │
    │  (Agent) │
    └──────────┘
```

### Configuration

The platform uses environment variables for configuration:

```env
# Database
DATABASE_URL="postgresql://user:password@localhost:5432/agenthub"

# Security (auto-generated by setup script)
JWT_SECRET="<your-jwt-secret>"
KEY_ENCRYPTION_KEY="<your-encryption-key>"

# API
NEXT_PUBLIC_API_URL="http://localhost:3000/api"
```

### API Reference

See [API.md](./docs/API.md) for complete API documentation.

### CLI Commands

```bash
# Connect agents
agent-hub connect [--email <email>] [--password <password>]

# Sync configuration
agent-hub sync [--no-heartbeat]

# Show status
agent-hub status

# Install hooks
agent-hub hook install
```

## 🔒 Security

- API keys are encrypted using AES-256-GCM before storage
- JWT tokens for authentication
- Rate limiting on all API endpoints
- Input validation using Zod schemas
- SQL injection protection via Prisma ORM

For security concerns, please email security@agent-hub.dev or see [SECURITY.md](./SECURITY.md).
